# /assets/images — Guía de fotografías

Esta carpeta está reservada **exclusivamente** para las fotografías reales de Henry.
El archivo `index.html` ya está enlazado a los nombres exactos de esta lista: basta con
guardar cada foto con el nombre indicado (mismo formato `.jpg`) y se reemplaza
automáticamente en el diseño, sin tocar ningún código.

Mientras un archivo no exista, esa zona del dossier muestra un placeholder editorial
(fondo gris + leyenda) para que el diseño se vea intencional y no roto.

## Recomendaciones

- Formato `.jpg`, buena compresión web (ideal < 500 KB por foto para que el dossier cargue rápido).
- El diseño aplica un tratamiento en **blanco y negro** a toda la fotografía (con un leve
  color al pasar el mouse). No es necesario entregar las fotos ya en B/N — se puede
  entregar a color y el mismo HTML se encarga del tratamiento visual.
- No reemplazar por fotografías de stock. El dossier está diseñado para que la fotografía
  real de Henry sea la protagonista.
- Si el nombre de un archivo no coincide exactamente con la tabla, esa foto no se mostrará
  y aparecerá el placeholder en su lugar.
